# image2-draw

用配置好的中转(OpenAI Images 兼容)生成图片,支持文生图与图生图。

## 用法

```bash
node <此skill目录>/scripts/gen.mjs --prompt "提示词" [选项]
```

| 选项 | 说明 |
|---|---|
| `--prompt "…"` | 必填。支持中文;含「竖版/横版/方图」等方向词会据此自适应尺寸 |
| `--ref a.jpg b.jpg` | 参考图(1~8 张,本地路径)。给参考图 = 图生图;多张 = 多源图语义 |
| `--size` | `adaptive`(默认)/ `auto` / `1024x1024` / `1536x1024` / `1024x1536` / `3840x2160` / `2160x3840`,或自定义 `宽x高`。自定义尺寸必须是 **16 的倍数**、最长边 ≤3840、宽高比 ≤3:1(所以 `1920x1080` 会被拒 —— 1080 不是 16 的倍数)。拿不准就用方向词 |
| `--quality` | `low`(默认,快)/ `medium` / `high`(慢但精细,适合手办/海报)/ `auto` |
| `--count N` | 生成张数 1~8(顺序请求,不并发)。**每张图各自输出三行**,即 N 张共 3N 行 |
| `--help` / `-h` | 打印用法并退出(退出码 0) |
| `--endpoint baseURL,key` | 直接指定端点,**可重复**指定多个(优先级最高)。key 里含逗号时改用配置文件 |
| `--out 目录` | 输出目录,默认 `<当前目录>/outputs/image2/` |
| `--timeout 秒数` | 单次请求超时。默认取 `~/.claude/image2-draw.json` 顶层的 `timeoutSeconds`,再退回内置 **180 秒**。**中转在 `--quality high` 下较慢,遇到超时要显式调大** —— 超时属于"可切换"错误,会换端点重发,可能重复计费 |

输出末尾三行:

```
ENDPOINT:<名称或地址>   ← 实际使用的端点
FAILOVER:<次数>        ← 成功前失败了几个端点(0 = 第一个就成功)
SAVED:<绝对路径>       ← 生成的图片
```

**把这些路径原样告诉用户**,不要只描述图。可以(可选)用 Read 看一眼结果确认质量。

## 提示词怎么写

- **文生图**:把主体、风格、材质、光线、构图、方向都写清楚。例:
  `一只柴犬的潮玩手办,搪胶质感,圆形底座,柔和棚拍打光,浅灰背景,方图`
- **图生图 / 人物一致性**(关键):先说"参考图是谁",再写"要变成什么"。
  > 图生图:参考图里是我和朋友在缆车里的自拍。左边的人:黑色短发、圆框眼镜、耳钉、白色插肩袖;
  > 右边的人:墨镜、竖起的短发、灰色插肩袖。**请保持两人的五官、发型、眼镜与穿着完全一致**,
  > 把两人做成 3.5 头身的 Q 版潮玩手办,站在圆形底座上,竖版。
- 多张参考图时明确写"以下参考图是同一人物的不同视角,请保持五官身材一致"。
- 想指定画幅就用方向词(竖版/横版/方图),比记尺寸可靠。

## 端点与密钥从哪来

优先级:CLI `--endpoint baseURL,key` > 环境变量(`IMAGE2_ENDPOINTS` 或 `IMAGE2_BASE_URL`+`IMAGE2_API_KEY`)>
`~/.claude/image2-draw.json` > DSH 配置回落。

`~/.claude/image2-draw.json`:

```json
{ "timeoutSeconds": 900,
  "endpoints": [
  { "name": "主", "baseURL": "https://api.example.com/v1", "apiKey": "sk-…", "model": "gpt-image-2" },
  { "name": "备", "baseURL": "https://backup.example.com/v1", "apiKeyEnv": "IMAGE2_API_KEY_B" }
] }
```

- **格式差异(重要)**:`IMAGE2_ENDPOINTS` 环境变量接受**裸数组**(`[{…},{…}]`)或**单个裸端点对象**;上面文件里的 `{"endpoints":[…]}` **信封格式只对文件有效**。把信封写进环境变量会得到一个没有地址的端点(脚本会指名报错)。
- `apiKey` 与 `apiKeyEnv` 二选一:`apiKey` 直接写字面值;`apiKeyEnv` 写**环境变量名**(脚本从 `process.env` 取值,所以密钥可以留在环境里、不落盘)。
  **注意两边语义不同**:DSH 侧的 `apiKeyEnv` 是 `~/.dsh/.credentials.yaml` 的引用名(由凭据库解析),Claude Code 侧读的是**环境变量**。
- **每次调用输出的是"每张图三行"**:`--count 3` 会打印 9 行(不是"末尾三行")。
- **退出码契约**:成功 0;`--help` 0;任何失败(缺参、坏参数、无可用端点、请求失败)1,并且失败信息以 `[image2-draw] 失败：…` 打到 **stderr**。
- 顶层 `timeoutSeconds`(1~3600)只影响 Claude Code 侧;**DSH 里配的超时不会传过来**,长任务要在这里或 `--timeout` 上显式设。
- **起点指针**:脚本把"上次成功的端点"记在 `~/.claude/image2-draw.state.json`,下次从它开始;设 `IMAGE2_NO_ROTATE=1` 可关闭该记忆,始终从第一个端点开始。

## 常见错误怎么处理

| 现象 | 含义与动作 |
|---|---|
| `没有可用端点`(stderr 上还会先出现一行 `未找到任何端点配置…`) | 按上面的方式配端点,配完重试 |
| `HTTP 400 …` | 参数/内容策略问题,**不会切换端点**(换端点也一样)。改提示词或换尺寸,别重试同一条 |
| `HTTP 401/402/403` | 该端点密钥无效/余额不足 → 已自动切换;若全部失败,提示用户换密钥 |
| `HTTP 524` | 上游可能**已经生成了图**。切换有重复计费风险;**全部端点都失败时**错误信息里会附一条重复计费提示。不要盲目反复重试 |
| 请求超时 | 同样可能**已经生成了图**,但**超时不会附带**那条重复计费提示(该提示只对 524 触发);每个端点的失败详情里会写「上游可能仍在生成」。不要盲目反复重试 |
| `全部 N 个端点均失败` | 逐个端点的原因都在消息里,原样转述给用户 |

## 不要做的事

- 不要自己去调用 OpenAI/其它生图 API 绕过本脚本(密钥与端点都由本脚本解析)
- 不要在未征得用户同意时批量生成很多张(`--count` > 2 会明显耗时并计费)
- 不要把密钥、`sk-` 开头的字符串回显给用户或写进文件
